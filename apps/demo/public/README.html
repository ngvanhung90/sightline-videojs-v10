Your site. Your sightline.

A real Video.js v10 React skin, designed around the picture. Controls sit below the video; Practice adds VTT chapters, direct speeds and an A–B loop without replacing the media instance.

Source repository and complete README ↗

Run the demo

git clone https://github.com/ngvanhung90/sightline-videojs-v10.git
cd sightline-videojs-v10
npm ci
npm run dev

Use the skin

Copy src/ into your React app. Install @videojs/react@10.3.0 and @videojs/core@10.3.0. Import SightlinePlayer and VideoSkin from that source directory, with Video from @videojs/react/video. Keep one media component mounted inside the skin.

Personalize

Set --media-accent-color, --media-accent-text-color, --media-border-radius and --media-font-family on the skin. Supply VTT chapters and captions tracks as children of Video.

Practice safely

Set A at the beginning of a detail, play forward, then set B. B must follow A by at least 0.25 seconds. Reset loop returns to the full video. Choosing a chapter or seeking outside a loop clears that loop. Pass a new sourceKey when changing media. A–B is disabled for live or unknown duration; hosts can force this through practiceDisabled.

Keyboard

Tab reaches controls; Enter and Space activate buttons. Space/K toggles playback, left/right seek five seconds, up/down adjust volume, M toggles mute, C captions, F fullscreen. Escape closes the chapter sheet and returns to its trigger. Native sliders support arrows, Home and End.
