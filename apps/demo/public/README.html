Your sightline.

SIGHTLINE is a native-video React skin for Video.js 10.3.0. It keeps one media instance across Watch and Practice. This review candidate has not replaced the existing Contra demo.

Six source files

Copy these paths, keeping their relative structure, into a directory such as src/sightline/. No unused Scaffold helpers or cn dependency are needed:

src/index.ts
src/player.ts
src/video/skin.tsx
src/video/skin.css
src/video/icons.tsx
src/video/use-practice-loop.ts

Use an existing supported React 18 or 19 application with TypeScript. Keep your runtime; install the Video.js packages:

npm install @videojs/react@10.3.0 @videojs/core@10.3.0

Compose a real video

import { I18nProvider } from '@videojs/react/i18n';
import { Video } from '@videojs/react/video';
import { SightlinePlayer, VideoSkin } from './sightline';

export function Film() {
  return (
    <I18nProvider locale="en">
      <SightlinePlayer>
        <VideoSkin title="Your film" sourceKey="film-01">
          <Video src="/film.mp4" playsInline crossOrigin="anonymous">
            <track kind="chapters" src="/chapters.vtt" default />
            <track kind="captions" src="/captions.vtt"
              srcLang="en" label="English" />
          </Video>
        </VideoSkin>
      </SightlinePlayer>
    </I18nProvider>
  );
}

VTT tracks are optional. Serve WebVTT as text/vtt; cross-origin media/tracks need suitable CORS headers. Keep the player, skin and Video mounted during mode changes. When changing assets, update the video src and sourceKey.

Set className="my-player" on VideoSkin. Check accent/text contrast together. The skin uses container queries for compact players and supports forced colors and reduced motion.

Practice contract

A–B is supported for seekable, finite, on-demand native Video.js Video at least 0.25 seconds long. It is disabled for live, unknown duration, unavailable ranges and other media adapters. A/B shows fractional times and the range length. An active loop has a visible Stop loop control in Watch and Practice. Changing source or seeking outside the range clears the loop. Browser scheduling affects loop precision; this is not a frame-accurate editor.

Keyboard

Tab and Shift+Tab move between controls. Enter/Space activate buttons. Space/K plays; left/right seek five seconds; up/down adjust volume; M mutes; C toggles captions; F requests fullscreen. Escape closes chapters and returns to the chapter trigger. Native sliders retain their own keyboard controls.
